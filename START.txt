NIGHTCACHE — WEB VERSION

This folder is for GitHub + Render deployment.
There is intentionally NO .exe here.

1) Upload all files in this folder to the root of your GitHub repo.
2) On Render: New -> Web Service -> connect GitHub -> select Nightcache.
3) Runtime/Language: Docker
4) Branch: main
5) Plan: Free (for testing)
6) Create Web Service

Render will build the Dockerfile and then give you a public https://....onrender.com address.
